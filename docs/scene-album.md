# 场景相册

相册与背包、收藏并列，打开后显示当前场景的真实照片。已领取角色的成员可以上传 JPG、PNG、WebP；浏览器缩放并转换为 JPEG 后保存到现有 SQLite/Turso 存储。

可见范围为所有八位成员，或多选指定成员；上传者始终可见，可修改分享范围、删除自己的照片。默认仅自己可见。列表和图片请求都在服务端验证登录和权限，图片不进入公开静态目录。

浏览照片时不显示“所有成员可见”“指定成员可见”等标注；可见范围仅在上传和编辑设置中呈现。

初始照片：KTV 两张合照给全部成员；POP MART 一张给 Laura、Jilly、Cora、Amber。初始照片没有个人上传者，由版本中的配置管理。

云端相册请求先同步权限，同步失败停止提供图片；更改等待持久化完成再返回成功。图片采用 64 KiB 数据块，兼容现有复制协议。单张保存不超过 768 KiB，每位成员总计 32 MiB；一次选择不超过十张，原文件每张不超过 25 MiB。

初始照片在 `server/album-seeds/photos.json` 中以 AES-256-GCM 加密保存，原始 JPG 不进入公开 Git 仓库。生产服务的 `ALBUM_SEED_KEY` 只保存在部署环境；图片接口先验证账号和可见范围，再解密。没有密钥的环境停止提供初始图片，测试使用独立的合成 JPEG。Vite 禁止直接读取相册种子目录，Vercel 仅将加密文件打包进服务端函数。个人照片按上传编号生成固定记录 ID，避免跨实例重试重复。相册读取以云端元数据为准，丢弃保存失败的旧权限，并恢复待同步的图片块；同步过程中发生新写入则拒绝当前读取，保留新写入。

验证：`npm test`、`npm run build`；构建后运行 `node scripts/verify-album.cjs`，它使用独立内存数据库，不修改已有账号或照片。覆盖真实多图上传、指定成员多选、查看原图、分享修改、删除及桌面/手机布局。
