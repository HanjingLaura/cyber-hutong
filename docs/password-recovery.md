# 忘记密码

登录页提供“忘记密码”。输入准确用户名、组织者提供的一次性重置码、新密码和确认密码后，即可修改密码，再返回登录。新密码仍需 10–128 位。已有账号无需重新注册；账号 ID、永久角色、背包、收藏、经历和照片权限都保持不变。

重置码只属于指定账号，有效期 30 分钟，成功修改密码后立即失效。重新生成同一账号的码会替换旧码。服务器只保存码的 SHA-256 摘要；错误、过期、已使用的码使用相同提示。接口限制请求频率、校验请求来源，并在持久化成功前保留旧密码和旧登录。

成功重置会撤销该账号的所有登录会话和控制权，本实例的在线窗口收到退出通知；其他实例在同步后拒绝旧会话。实时连接重新连接时需要有效登录签发的新票据。

## 组织者生成重置码

在持有数据库管理凭据的项目目录运行，仅把返回的码私下交给这个账号的本人。

正式环境：

```powershell
node scripts/reset-code.mjs --production --env-file .env.production.local --username laura
```

`--username` 必须是已注册账号的准确用户名。环境文件需提供 `TURSO_DATABASE_URL`、`TURSO_AUTH_TOKEN`，以及非默认数据库所需的 `HUTONG_TURSO_PREFIX`。凭据不进入网页，也不提交 Git。正式环境缺少数据库配置时，命令会报错，不会改用本地库。

本地环境：

```powershell
node scripts/reset-code.mjs --db data/mvp.sqlite --username laura
```

命令只生成重置码，不修改密码。数据库写入成功后才会输出码；不会通过网页提供生成接口。可以随时重新生成新的码，无需变更账号或角色。

验证覆盖指定账号、单次使用、过期/替换、密码长度、并发消费、会话撤销、保存失败回滚和 Turso 跨实例同步。`node scripts/verify-password-reset.mjs` 检查桌面和手机上的错误提示、修改成功、清除秘密字段和使用新密码登录。
