# POP MART 当前试玩

场景使用 assets/drafts/popmart-store-v3.png，来自用户指定参考的 cyber-hutong 项目像素店铺。保留立体侧货架、中央开放陈列台、后方收银台与粉色盲盒机；移除商品照片拼贴、重复主题标题和额外柜台。中央陈列台前景裁片与碰撞区对应同一背景物件。机器放大图从同一粉色机柜原图区域取用，保持像素风。

靠近陈列台按 E，可选玩具总动员、比奇堡或经典 IP，再选三排六列中的具体盒位抽取。库存生成时独立均匀预分配商品，抽取不重抽，不宣称现实官方概率。靠近盲盒机按 E 后直接抽一盒，不出现主题和盒位选择，机器库存全部抽完后自动补充。

十款记录沿用已建立的商品池：Woody、Buzz、Bullseye；SpongeBob、Patrick、The Farmer；MOLLY、DIMOO、SKULLPANDA、LABUBU。经典池是游戏精选组合，不是现实同系列整箱。IP玩具角色的像素图生成被工具拒绝，类别 other；当前结果显示像素包装与收藏名称，没有使用商品照片或错误对应的通用玩偶冒充已完成的 IP 像素图。

浏览器 localStorage hutong-popmart-v2 保存库存与收藏。切换场景和刷新保留收藏；免费，无货币系统。收藏只展示已拥有的款，抽取中禁止重复点击。

官方商品资料仍保留在已有商品目录中；场景和开箱界面不再直接显示这些商品照片。完整素材来源、提示词、未完成部分见 docs/pixel-scene-update.md。

验证：场景通道与陈列台碰撞，直接抽取后收藏增加，盲盒机无主题或盒位选择，像素机柜放大显示，TypeScript / Vite构建通过。
