# 休息室餐桌与贩卖机交互

- 贩卖机：走近按 E，选择可乐、气泡水、薯片、面包、火腿肠或辣条。可点击按钮或按 1–6，Esc 取消。全部免费，不显示金额或零钱，不存在扣费和余额判断。
- 一次拿一件，已有物品时先放到桌上，避免直接覆盖并丢失物品。
- 餐桌：站在桌边按 E 放下手里的物品，空手按 E 拿回桌上物品。每桌暂存一件，桌上已有物品时不会覆盖它。
- 坐着时按 F 或侧栏桌面操作按钮放下 / 拿回；E 和 Esc 仍然起身。
- 放下后使用相同的独立物品纹理显示在桌面；库存、桌面状态与胡同两视角共享到刷新前。
- 咖啡继续走冲泡 → 出杯 → 拿起流程。杯子、六种产品均使用现有持物动作与朝向遮挡规则。
- 五种新增产品使用原生小尺寸像素纹理，纹理定义在 src/product-textures.ts；现有气泡水瓶和咖啡杯继续复用。

验证：构建通过。浏览器实际操作咖啡冲泡、带咖啡坐下、桌面放下 / 拿回，六种商品领取、数字选择、Esc 取消、薯片跨场景保留。页面没有货币文字或余额字段，浏览器控制台无错误。原场景 UI 和视觉保持，无新增通用应用外壳或虚构品牌。

## 桌侧碰撞、遮挡与贩卖机内部展示

餐桌使用统一的地面排序线 y=267，而不是素材最底部的 y=283。人物走到桌前时绘制在桌前，坐着或站在桌后时仍由桌面遮挡。桌面物品跟随桌子的排序线。桌边碰撞椭圆半径按桌宽加人物脚底余量计算，避免从侧面进入桌下。

贩卖机面板改为橙色机身、玻璃窗内的两层货架、每类三件陈列、货架商品标签和取物口；保持六种免费领取、点击货架或按 1–6、Esc 关闭。

验证：桌侧持续向内走被阻挡；人物位于桌前侧时头部不被桌面盖住；货架选择可乐成功，面板关闭。构建通过，浏览器没有错误或警告。截图：output/playwright/table-edge-fixed.png、vending-interior.png。

## 多物品桌面与侧向交叉步行

每桌六个固定位置，可以放不同产品或重复产品。再次放下不会覆盖其他物品；满桌时保留手中物品并提示。空手取回：一件直接拿回，多件显示选择列表，可点击或按对应数字。取走中间物品后，其他物品的位置不变。坐着 F、站着 E 的操作保持不变。

侧向步行由同一个八阶段相位驱动：前后腿交替迈步、抬脚、经过身体下方、交换前后脚。保留原人物的头部、衣服、手臂与持物挂点，只在运行时绘制裤腿和鞋子；空手上身帧与腿部相位对应，前向的腿配后向的同侧手臂。左右方向、胡同双视角、空手和持物均使用该腿部循环。停下、坐下时恢复原人物完整静止素材。

验证：同桌放满六种产品，第七件未覆盖桌面且仍在手中；三件时选择中间的气泡水拿回，剩下物品原位保留；检查空手 / 持物左右行走和停止。构建通过，浏览器控制台无错误与警告。截图 table-six-items.png、gait-empty-left.png、gait-empty-right.png 保存在 output/playwright。

## 小幅摆臂与向上持物稳定

左右步行保留相同的手腿反向相位，在渲染时缩小原素材手臂外围的摆动范围，肩部渐变连接，头部和中央衣服保持原像素位置。持物动作不改变握持区域。

向上持物第一帧 cell-12 原登记误选左侧空手。登记脚本对背面静止及四个步行帧明确选择右侧持物手，避免四帧播放时物品在左右手之间跳转。四帧现在均 side=1；浏览器检查四帧持物持续可见。构建通过，控制台无错误和警告。
