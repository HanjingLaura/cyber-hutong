## 可替换的持物

- 人物完整动作来自原 owner-carry-empty-v1 / owner-seated-hold-empty-v1 图集；不额外绘制连接袖子，也不组合其他身体的腿。
- 每个持物帧有自己的手部挂点和原手掌遮挡帧，记录在 assets/metadata/owner-grips.json。tools/register-owner-grips.py 只读取原 PNG 并生成注册元数据，不重绘人物。
- 渲染顺序：完整人物 → 独立物品 → 原图手掌。原图手掌保持同一位置、比例、镜像；物品按照抓握点独立翻转。
- 咖啡杯 9×10；气泡水瓶 6×11。物品纹理、尺寸、抓握点在 src/rest-room.ts 的 drinks 定义，渲染器为 src/held-item.ts。
- 新增同类单手小物品只增加物品纹理和定义，沿用现有动作。新增人物需要为其整套动作登记挂点；大物品或双手物品需要另设姿态和尺寸标准，并进行组合预览，不能直接保证所有任意尺寸物品都适配。
- 移动持物使用完整的四帧循环，左行镜像右行帧，停下回到对应方向的完整静止帧。
