# 个人彩蛋的视觉回应

| 主人 | 彩蛋 | 视觉反馈 | 台词 |
| --- | --- | --- | --- |
| Sid | Ani | 轻跳、摇摆、像素爱心；反向视角保持位置正确 | Sid，先休息一下，我陪着你。 |
| Suki | 水豚噜噜 | 左右踩拍子、浮动音符；镜像同步 | Suki，跟上我的拍子～ |
| Kay | 图图 | 连续蹦跳、打气星光 | Kay，再来一组！ |
| Cora | 巴斯光年 | 短暂升空、喷气和星光 | Cora，准备起飞！ |
| Jilly | 朱志鑫 | 摇摆、音符、短暂舞台光 | Jilly，这一首唱给你。 |
| Amber | 富贵貂 | 摇摆、像素金币与金光 | Amber，今天也富贵！ |

动作和像素特效约 2.4 秒，气泡 5 秒；表现用的金币不产生道具或经济奖励。保留本人、距离、主控窗口和 3 秒频率校验。其他在场玩家可见；经历及当时台词只记录在互动者的回看中。Ani 仍只在 Sid 的 L1 工位办公时出现。

服务端把每个 NPC 最近一次回应写入可复制 SQLite 表，最多六条记录，过期按时间过滤，不每帧写入。长连接存在时每个 Vercel 实例共用一条约 1 Hz 的副本刷新循环，最后一条流结束后停止；网络恢复后继续刷新。HTTP 响应让本人立即显示，旁观者通过 SSE 显示。客户端时间单调前进，保留过期的最新标记，避免旧响应回放；登出和销毁后丢弃未完成请求的响应。

旁观者收到时播放剩余的反馈，同步慢于 5 秒有效期时直接跳过，不补播旧动作。副本读取成本随活跃实例数量增长，已有的行级后写覆盖限制保持不变。

复用现有角色素材；没有新增下载资源或页面外壳。场景 update 驱动角色姿态，既有 100 ms UI 周期更新小型透明 canvas 并复用气泡节点。开启系统“减少动态效果”时，角色保持原位，显示静态像素标记及台词。

验证命令：

```powershell
node --test server/npc-feedback-client.test.mjs server/npc-ui-client.test.mjs server/npc-reactions.test.mjs server/stream-replica.test.mjs server/easter.test.mjs
node scripts/verify-npc-feedback.mjs
npm run build
```

浏览器验收使用独立内存数据库和临时账号，不修改正式数据；截图保存在 `output/playwright/feedback-*.png`。

验收结果：六个彩蛋的本人/旁观者气泡、像素绘制、角色动作及到期清理全部通过；Ani 反向视角、375 px 手机和减少动态效果通过。全套服务端及客户端行为测试 109 项通过，包含八人、32 条事件流的并发场景。独立代码审查 APPROVE；架构审查 WATCH，无阻塞项，读取成本和五秒有效期的边界见上文。
