# 八人完整内测版：交付与验收

2026-10-03。保留现有 14 个房间，按交互、门口地图、共同世界、彩蛋、收藏顺序实施；没有新增批量场景、大模型、货币或公开平台。

## 已实现

| 范围 | 修改 |
|---|---|
| 交互 | 统一座位和设备的脚点、接近点、朝向、最近目标和 E / Esc 操作；沿用修正的厕所深度、连续洗手台、平行窗户、餐桌和独立拼豆椅子。八人复用统一动作索引与持物规则。 |
| 地图 | 全部房间出口和三组地点，目的地预加载、确认切换、失败重试；服务端检查出口与互动状态。保留角色、手持和私聊。 |
| 共享状态 | 桌面、冰箱、储物点、门、窗帘、盲盒库存、赠送和消耗由服务端确认；稳定编号、递增版本、事务和幂等重试。 |
| 占用恢复 | 座位、机台、运动设备、钢琴互斥，退出、接管、断线超时、重启释放；重连重新读取快照，失去控制时停止本地设备与音频。 |
| 人物 | 本人确认档案、事件规则、回复间隔、在线不代言。共享彩蛋条件和时钟，Celine 提问不生成 Amber/Jilly。 |
| 留存 | 账号收藏册、盲盒、扭蛋、拼豆草稿与作品、五种小游戏最佳成绩持久化。 |
| 工程 | 抽出导航、WorldClient、房间/交互/彩蛋配置；房间素材分批加载、角色缓存、仅变化物件重绘；八账号邀请码和 SQLite 备份恢复。 |

新增 `/api/transition`、`/api/object`、`/api/lease`、`/api/progress`。SSE 包含物件版本、个人进度版本、占用、共享时钟与彩蛋状态；保留原账号、聊天、角色归属和手持数据。

## 验证记录

- 类型检查与生产构建通过，13 项集成测试通过。覆盖八账号限制、唯一角色、私聊隔离、抢座、物件争抢、幂等重试、旧版本保护、场景出口检查、设备互斥、赠送、短断线、重启和 WAL 备份恢复。
- 八个隔离浏览器账号验证联机。全部 14 房间通过门口地图进入；座位测试以夹具准备附近位置，然后真实方向键接近、E 坐下、Esc 起身。另以房间碰撞规则检查入口到座位可达；不把夹具准备冒充完整房间步行。
- 实际键盘完成冲咖啡、放桌面、另一人拿取、放冰箱、另一人取回。双方私聊可见，第三人不可读取。
- 娱乐室五种游戏实际操作：扫雷翻格、蜘蛛发牌、抓娃娃下降、投篮出手、空气曲棍球移动；E 正常退出。
- 69 个座位键盘复测通过，原始结果 `output/ui-audit.json`。跑步机启动和变速、哑铃完成一次弯举、钢琴发音与 E 结束通过。
- 人为中断目标素材请求：留在原房间，恢复请求后直接重试成功。断网被识别，恢复后重新连接；同账号观看窗口可用 Esc 关闭收藏册，接管后旧窗口退出钢琴、停止音频和键盘控制。
- 盲盒、扭蛋与实际熨烫作品刷新后保留，另一个隔离浏览器可读取三项收藏（含拼豆缩略图）。八人同时切换到两个房间，稳定快照中每个房间四人、没有重复角色。
- 自动服务端负载 30 分钟：8 玩家、32 SSE 连接、9,978 轮更新，无错误。`output/next-mvp-soak.json` 保存采样。这是收尾修复前的服务版本；浏览器恢复测试包含刷新和重连，不等同于最终构建八位真人连续玩 30 分钟。
- 检查全窗口像素画面，没有新增页面外框、虚构品牌、装饰标签或通用 SaaS 壳。厕所截图：`output/playwright/bathroom-next.png`。

测试数据库为 `output/ui-acceptance.sqlite`，与正式数据库分离，不占用正式角色。`scripts/ui-mvp-server.mjs` 站位夹具只在本机验收服务启用，正式服务没有这个入口。

## 内测边界

八人的性格资料和离线代答授权必须由本人确认，不能代填或推断。还需八位真人在最终构建中连续试玩至少 30 分钟，检查不同设备窗口、素材观感、手感和完整朋友游玩路线；自动负载不能替代真人验收。

服务端检查移动速度与交互锚点，完整家具碰撞网格仍在客户端。小游戏成绩用于朋友留存，没有竞技防作弊。当前单实例 SQLite，尚未验证公网部署、跨实例扩容或触屏操作。大入口按范围逐步拆分，既有房间内部玩法控制器继续保留。
