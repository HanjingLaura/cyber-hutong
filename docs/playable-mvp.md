# 八人可玩 MVP

当前 14 个房间接入门口地图、共享物件、账号收藏和共享彩蛋。验收见 [本轮交付](next-mvp-acceptance.md)。

## 开始游玩

本机 Node 22.17，使用 node:sqlite。开发运行 npm run dev；正式运行 npm run build、npm start，访问 http://127.0.0.1:8788/ 。单独 preview 不提供联机后端。

首次启动在 .env.local 自动生成 HUTONG_INVITE，也可预先配置。设置 → 账号注册填写邀请码，最多八个账号，每人领取唯一角色，退出不释放归属。邀请码、原始照片和数据库不作为静态资源。

WASD / 方向键移动；E 使用或结束，Esc 起身或返回，F 保留已有次级操作。钢琴原 E 音符改为 R。靠近出口按 E 打开地图，选地点并确认。顶部只有地图、人物、聊天、设置。画面全窗口等比例显示，像素保持清晰。

## 共同世界

共享桌面、冰箱、储物点、门、窗帘、盲盒库存、物品赠送和消耗由服务端确认。稳定编号、递增版本、SQLite 事务和幂等编号保证争抢只有一人成功、重试不复制物品；移动上报不改变物品归属。小游戏棋局个人独立，机台、运动设备和钢琴互斥。

座位与设备是临时状态，退出、接管、断线超时或重启释放。短断线保留人物位置与座位，重连获取快照。失去连接或操作权停止本地设备和音频。同账号只有一个控制窗口，其他窗口观看或接管。

配置了 PartyKit（见 [partykit.md](partykit.md)）时，其他玩家的位置与在线状态以 PartyKit 房间为准；SSE 继续推送聊天与物品事件。未配置时行为与原先单实例 SSE 一致。

盲盒、扭蛋、拼豆草稿和作品、五种小游戏最佳成绩按账号保存；设置 → 收藏册查看实际获得内容。普通供应免费，没有货币、任务或签到。

## 人物与彩蛋

人物面板可私聊、附近招呼和赠送。私聊仅双方可见，场景聊天和气泡只在当前房间传播。设置 → 角色档案填写本人确认的习惯、表达方式与例句，可标记 [办公]、[碰面]、[运动] 事件。规则回复有间隔，真人在线不代言，离线回复需本人确认授权；不从照片推断性格，不接大模型。

Sid 在胡同办公触发 Ani，Suki 在舞室触发噜噜，Kay 在健身房触发图图；shared/npcs.json 集中配置，服务端统一判定。Celine 的行动、问话使用共享时钟，“Amber 呢？”更常出现，“Jilly 呢？”较少，不随机生成 Amber/Jilly。

## 备份恢复

npm run db:backup 使用 VACUUM INTO 备份已提交内容，包含已提交 WAL，并做完整性检查。npm run db:restore -- 备份文件 新数据库路径 恢复到不存在的新文件，不覆盖现有数据。停服后用 HUTONG_DB 指向恢复文件，再启动。当前单实例 SQLite，仅面向八人内测，未公网部署。
