# 五道口站像素场景

新增顶部「五道口站」入口，沿用现有 Laura 人物、手持物品、步行动画和像素渲染。

## 场景与交互

- 高架站台、金属顶棚、黄色站牌、银蓝色停靠列车。
- 三组双扇滑门一起开关，靠近任意一组按 E，或点击侧栏互动按钮。
- 开关约 750ms；途中可以反向操作。切换场景暂停动画，返回继续，保留开关状态。
- 人物活动在站台上。车门打开也不解除站台边界，本版没有上车与发车功能。
- 背景只画敞开的车厢，动态门叶单独绘制，并裁切在实际门框内。

## 验证

实际浏览器检查全开/全关、中途反向、开门时持续向前仍不能进入车厢、切换场景暂停后恢复、右侧门附近点击按钮控制全部车门。
界面沿用原有功能导航，没有添加浮动白色外壳、虚构品牌或装饰卡片。
