## 目标与已确认方向

以用户确认的线上人物形象、像素主题和调性作为正式视觉基线，优先让现有场景操作稳定，再整理可持续扩展的人物素材库，补齐聊天频道并接入真实人物 Agent。

- 场景切换提供两种模式：默认走到出口，设置中可开启地图快捷切换。
- 聊天分为公共大厅、当前场景、私聊。
- 公共频道中的 Agent 被明确 @ 才回应；私聊直接回应。
- Agent 首轮以 Laura 为试点，验收后再扩展其他人物。
- 人物素材按人物独立归档，新动作沿用同一形象与制作标准。
- 界面沿用现有规范，不新增虚构品牌或通用 SaaS 外壳。

## P2：三类聊天频道

| 频道 | 可见范围 | 切换场景后的行为 |
| --- | --- | --- |
| 公共大厅 | 所有已登录成员 | 保持同一频道 |
| 当前场景 | 当前房间成员 | 跟随当前房间切换 |
| 私聊 | 对话双方 | 保留对话对象 |

- [x] 聊天面板提供清晰的频道切换，分别管理草稿、历史与未读。
- [x] 聊天与历史接口明确频道类型，场景范围由服务器确定，私聊指定对象。
- [x] 已有公共消息归入场景频道，已有私聊保持双方可见；兼容旧请求和历史记录。
- [x] 历史查询与实时推送使用相同的可见性规则，只有场景消息显示人物气泡。
- [x] 公共频道通过成员选择器发送 @；Agent 回复不会再次触发其他 Agent。

验收：使用至少三个账号验证跨场景大厅、场景隔离、私聊隔离、未读与草稿；连续切换频道和房间后，历史与实时消息不串频道、不重复。
