# KTV 包厢

2026-10-08 加入现有像素世界。门口地图的「休闲」分组包含 KTV；结束互动后走到出口 `(580, 321)`，沿用按 E 打开地图、选择目的地并确认的流程。

## 场景与素材

包厢以 640×360 画布呈现，参考用户提供的两张室内照片，保留黑色沙发、铜色细节、汽车主题墙面和黑白迷宫纹地砖。桌子、沙发、音箱与点歌台设有行走阻挡，五个沙发座位沿用现有落座机制。

背景使用内置 `image_gen.imagegen` 生成。素材来源、完整生成与修改提示、地图缩略图来源记录在 [ktv-room-v1.json](../assets/metadata/ktv-room-v1.json)；用户的私人参考照片未加入仓库。

点歌弹窗和包厢状态栏沿用 [theme.css](../src/theme.css) 的深橄榄色背景、暖色文字、直角边框按钮与字体。屏幕内容、拍点和灯光绘制在现有像素投影上；本次扩展没有添加虚构品牌、整页浮动圆角白色外壳或通用 AI/SaaS 装饰。

## 操作

- 桌面：WASD / 方向键移动，靠近物件按 E 互动；落座或拿麦后按 E / Esc 结束互动。
- 触屏：沿用摇杆和主互动按钮；拿麦后可在状态栏点击「唱一拍」或「放回麦克风」，触屏按钮至少高 40px。
- 点歌：走到右侧点歌台，选择《胡同夜唱》《晚风合拍》或《朋友的副歌》。三首均为原创 32 拍短曲，队列最多 12 首（含当前歌曲），支持暂停、继续播放和切歌。
- 灯光：靠近右侧灯控互动，在暖光、紫光和派对模式间循环切换。
- 唱歌：空手靠近麦克风拿麦，跟着屏幕和状态栏的八拍指示，按 Space 或点击「唱一拍」。麦克风沿用现有设备租约，同一时间由一位玩家占用。
- 伴奏：每位玩家主动点击「开启伴奏」后播放合成声音；可随时关闭，离开场景会停止。

## 同步与边界

已登录联机时，当前歌曲、队列、播放进度和灯光通过现有共享物件 HTTP / SSE 通道同步；角色位置、座位和拿麦活动沿用既有联机机制。节拍得分与伴奏开关属于本地状态，不设共享排行榜。

每拍只记一次尝试：距离拍点不超过 90ms 得 100 分，190ms 内得 60 分，其余为 0 分。暂停或没有歌曲时不能得分。玩法仅比较按键或点击时机，不采集真实声音、不识别音高，也不提供商业卡拉 OK 录音。

## 验证

```powershell
npm test
npm run build
# 先启动 npm run dev，再执行桌面与触屏场景检查
node scripts/verify-ktv.cjs
```

场景检查默认访问 `http://127.0.0.1:5173/?debug=1`，可用 `KTV_TEST_URL` 指定开发地址。该检查使用访客开发预览，覆盖点歌、暂停、切歌、灯光、座位、桌椅阻挡、伴奏和节拍互动；截图保存到 `output/playwright/ktv/`。共享物件规则与设备占用由服务端测试覆盖，访客场景检查不替代真实多人验收。
