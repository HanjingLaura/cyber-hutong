# 走路与跑步参考核查

参考原作者教程：
- https://www.slynyrd.com/blog/2024/5/24/pixelblog-50-human-walk-cycle
- https://lifebe.com.au/artistic/pixel-art-tutorial-running-animation/

当前 v4 每人有两张走路、两张跑步姿势。avatar.ts 以 250ms/170ms 交替选帧。这种简化并非一定错误，但当前图集缺少腿交叉、承重和抬腿阶段，难以检查同一条腿是否连续移动，遮挡正确不能单独证明步态正确。

下一版应先验证一个人物的完整周期，再用于九人的完整重绘，不移植肢体。建议采用八帧走路、八帧跑步；帧数是本项目选择，不是引擎要求。

始终用近侧/远侧跟踪四肢，避免把屏幕左边/右边误当人物左腿/右腿。侧视相机固定时，近侧四肢保持身份，改变的是前后摆动的位置。远侧腿用稍深的颜色；近侧腿与身体连接、交叉处的轮廓须持续一致。

|帧|腿部阶段|手臂关系|
|---|---|---|
|0|近腿前伸落地，远腿在后|近臂后摆，远臂前摆|
|1|近腿承重，远脚抬起|两臂从极值回摆|
|2|远腿从近腿旁经过|两臂接近中间位置|
|3|远腿向前抬起|近臂向前，远臂向后|
|4|远腿前伸落地，近腿在后|近臂前摆，远臂后摆|
|5|远腿承重，近脚抬起|两臂从极值回摆|
|6|近腿从远腿旁经过|两臂接近中间位置|
|7|近腿向前抬起|近臂向后，远臂向前|

跑步须另画：蹬地、腾空、落地、缓冲，摆动腿弯膝收起，手肘弯曲。同侧手臂与腿反向摆动，左右两组相差半周期。跑步不能仅加快走路帧率或画更大的跨步。

固定逻辑像素尺寸、头身比例、轮廓与角色身份；各帧保留同一定位点，身体高低变化画进完整帧。逐帧检查落脚和交叉，再检查循环播放、游戏左右行走、人物停止和重新启动。九人批量重绘须在一个人物完整动画验证通过后进行。
