# Laura 第一批原始素材

使用用户提供的白色连帽衫照片和 asset-standard-v1.md，通过内置 imagegen 生成。原始照片保存在 references/private/laura，不进入前端包。照片没有展示裤子与鞋，深灰裤子、浅色鞋是游戏造型选择。

素材目录：assets/characters/laura/v1。所有 PNG 原图保留 alpha，未使用脚本修改像素；失败或早期版本按独立文件保留。完整生成提示词在 prompts/；文件、方向和目标挂点在 manifest.json。

原始图集尺寸由生成器决定，不能直接当作 64×80 的逻辑帧导入。检查页使用一套固定身体倍率和明确登记的源坐标；没有按每帧自动裁边、独立缩放，也没有拉长裤腿或鞋子。

可打开 /laura-assets.html 检查四倍放大的固定画布、地面线、座面线与挂点，并切换脚底或臀部对齐。侧坐源图的座面到脚底约 13.7 世界单位，标准是 16，固定比例下仍不能同时对齐。检查页明确标出未通过，没有宣称这批已解决穿模。

遵照标准第七节“样板完成几何及放大视觉验收，再生成六帧行走、坐下与起身过渡”，本批没有扩散生成尚未校准的行走和过渡模板。下一步必需工作是精确像素整理/关节校准、手臂绑定及两个座具样板的接触验收，然后才扩展动作。

现有电脑、胡同两个视角、休息室场景及运行中的角色素材没有被这批候选图替换。新增的座具仅用于素材适配样板。

## 动作播放预演

检查页顶部新增独立播放区，可切换四个朝向并执行拿杯、放下，以及坐姿/站姿切换。手臂用源图肩部与手掌坐标绑定，物品位于手掌图层下方；圆形手掌覆盖握持点。当前展示的是挂点运动，杯子从展示台移动到手中，不包含人物走到台前、伸手接触的完整取物流程。

坐下与起身目前仅切换身体姿势和位置，没有三帧屈膝过渡。六帧走路尚未制作；侧坐脚底悬空、物品柔光边缘仍未通过验收。播放区不能视为可投入游戏的完整动作包。
