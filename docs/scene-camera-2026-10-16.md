# 场景框选拍照

工具栏「拍照」会定格当前游戏画布，支持鼠标或手指拖动框选。默认全景；可反向拖动、拖到边缘，并用方向键移动选区、Shift+方向键调整大小。裁剪按原始画布像素计算，不受页面缩放或设备像素比影响。小于8像素的边长不可确认。

「预览照片」裁剪定格画面后进入现有相册确认界面。玩家可填写说明、沿用指定成员/所有人的可见范围设置，再点「存入相册」；默认不勾选其他成员，即仅自己可见。取景取消、预览取消或 Escape 都不会上传照片。保存失败可使用相同 requestId 重试，避免重复存图。

使用 Phaser renderer.snapshot，在下一帧读取画布，兼容 WebGL 和 Canvas，不读取页面工具栏、不调用设备摄像头。前端裁剪后沿用 preparePhoto 与现有相册 JPEG 上传、权限校验、配额和 Turso 持久化，无新增服务端接口。账号或场景改变会撤销取景；关闭后恢复游戏焦点并释放照片草稿资源。

验证：scripts/verify-camera.mjs 使用真实登录账号和 Google 场景，覆盖渲染快照、反向框选、精确448×216裁剪、实际图像内容、两阶段取消、Escape、键盘微调、保存失败重试、重新打开相册、跨账号私有/公开权限，以及手机真实触摸拖动与确认。输出 output/camera/verification.json 和截图。几何回归位于 server/camera-selection.test.mjs。
