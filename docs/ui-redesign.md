# 像素界面改版

## 范围与审查

本轮接续桌面目录内尚未提交的 Node + SQLite + 原生 HTML 私聊实现，
不迁移框架、不覆盖现有素材，不把独立行为模块误写成已实现的联机世界。
原界面存在全局 form/main 样式串扰、手机布局拥挤、纯文字成员列表、
技术配置暴露给玩家、切换聊天的异步竞态及历史读取停留在最早 100 条等问题。

保留根路径、账号字段、八名成员、私聊接口和子路径部署适配。
设计参数 3 / 3 / 4，沿用胡同场景的深绿色与灰白配色、直角、实线边框、
硬阴影和原始人物素材。没有新增营销口号、虚构品牌或通用 SaaS 外壳。
design-taste-frontend 用于审查、视觉一致性与可访问性；
登录流程和实时聊天按实际产品需求处理，不套营销页区块规则。
《元气骑士》只作为直接选择、按键反馈和返回操作的交互方向，
没有复制其素材，也没有宣称已实现移动、攻击或完整场景地图。

## 操作

- 成员列表：点击，或方向键选中后 Enter 打开。
- Enter 发送；Esc 返回成员选择；手机提供“成员”和“返回”按钮。
- 手动 / 托管保留来源标记，自动回复不会冒充本人。
- 草稿按对话分别保留，发送时可继续编辑；断线重连后补取聊天记录。
- 登录 / 注册 / 忘记密码 / 重置密码使用同一像素风界面。
- 深浅模式随系统切换；无常驻动画；按钮有焦点和按压反馈。

## 后端

注册绑定仍在 SQLite 事务内完成。新增认证限频、密码长度上限、
15 分钟一次性重置码、重置后撤销会话、SSE 会话复核。
真人接管时取消在途自动发言；真人消息先写库并通知，再等待自动回复。
历史读取改为最近 100 条的稳定时间顺序。

管理员核对身份后运行：

```sh
npm run reset-password -- Suki
```

只把生成的重置码私下交给本人，不上传、不写进公开日志。
忘记密码入口不发送邮件，也不声称已发送；页面提示联系管理员。

## 验证与边界

`npm test` 覆盖行为、账号、重置、聊天隔离、接管竞态、限频与静态资源。
浏览器检查使用 `node scripts/ui-smoke-server.mjs`：
仅绑定 127.0.0.1:8798，内存数据库，固定测试密码 ui-test-only-123，
不读取真实数据库和外部模型密钥。此脚本不能作为生产启动入口。

目前可运行产品仍是账号 + 私聊。移动、场景切换、靠近交互、
座位遮挡、组队寻路尚未接入，不能把本次 UI 更新当作完整游戏。
现有 Vercel 入口仍使用 /tmp SQLite，属于临时预览：
实例回收会丢失账号和消息，多实例也不共享状态。
正式使用应部署 Node 常驻进程 + 持久磁盘，或另行迁移持久数据库与实时服务。
本轮未自动部署或迁移线上数据。
