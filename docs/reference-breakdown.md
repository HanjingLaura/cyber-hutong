# 第一批真实照片：场景拆解与素材边界

收到的四张照片：1 休息室；2 胡同朝开放办公区方向；3 胡同朝尽头墙方向；4 用户本人。

原图复制到 references/private/，不作为公开客户端资源。用户显示名和座位等待补充；不从旧项目或照片中的其他人推测。

## 胡同的确定结构

- 只保留靠墙的八个工位，两侧各四个；尽头墙内形成一个独立胡同空间。
- 桌子沿左右两侧墙排列，椅子位于桌子内侧，中间保留可行走通道。
- 左右侧桌面分别面向左右墙，不能改成中间两排相向的桌岛。
- 两侧各是一整条相连的浅木桌面，不能把八个座位画成八张带间隙的小桌；八个座位与操作点分别配置。
- 尽头白墙保留红中国结；右侧保留公司文化墙视觉特征。
- 白墙、灰色地毯、浅木桌、黑色网椅为主；红色与深绿作为实际装饰色。
- 朝开放办公区的其他桌排、照片中其他人员、临时箱子和遮挡物不纳入此八人地图。
- 顶部管道与灯在照片中有辨识度，但游戏采用屋顶移除的斜俯视；不让天花板覆盖可玩区域。

## 分层决定

| 层 | 胡同元素 | 休息室元素 | 处理 |
| --- | --- | --- | --- |
| 基础结构 | 白墙、灰地毯、踢脚线、红中国结、文化墙底饰 | 白墙、灰地毯、右侧 Go! 墙饰、固定窗外/墙面部分 | 基础场景，不包含人物和可变物件 |
| 固定家具 | 两侧连续桌面、桌脚、固定隔挡 | 左侧台面与底柜、右侧圆桌 | 独立透明素材，按基底排序；较大物件可拆前后层 |
| 座位 | 黑色网椅及椅背 | 青绿色休息椅 | 独立透明素材、座位锚点、占用状态与坐姿配套 |
| 状态对象 | 笔记本电脑开合/屏幕 | 橙色零食柜、银色冰箱、咖啡机、玻璃出入口 | 独立状态素材与交互点；门框可固定，门扇独立 |
| 可附着小物件 | 咖啡杯、手机、个人确认的摆件 | 杯子、零食、少量台面绿植 | 独立道具，固定摆件和可领取物品各自配置 |
| 纯装饰 | 用户确认后保留的桌面绿植/小摆件 | 衣架、少量实际台面用品 | 独立静态素材，可做遮挡；首轮不扩充交互 |

“固定”不等于“烘焙进背景”。桌子需要遮挡，椅子需要占用，台面要承载咖啡机；这些保持独立。

## 用户本人：可见外貌参考

- 深棕到黑色的直发，中分，长度到肩附近。
- 较大的细黑框圆角眼镜，保持实际轮廓，不简化成小圆眼镜。
- 深色翻领上衣，照片里可见细项链。
- 只据照片设计可见外貌，不推测性格、职位或现实关系。
- 下半身没有参考：第一轮仅用朴素深色长裤和鞋作为样稿占位，不写进真人档案；后续可按用户说明替换。

## 第一轮生产与验收

1. 胡同空场景基础：仅墙、地面与辨识墙饰，为左右各四个工位留位置。
2. 人物四向待机风格稿：采用本人照片，共用一种头身比例与像素密度。
3. 胡同桌子/网椅/电脑透明素材：同一机位和尺度，先验证一套工位。
4. 独立图层合成与交互样板：确认八工位布局，验证走路、桌前桌后遮挡、坐下和起身。
5. 休息室独立图层在胡同风格锁定后沿用，避免两张场景各自生成不同画风。

生成概念图只用于检查风格；运行背景不能使用把桌椅、人物、电脑画在一起的整张概念图。每张生成图记录实际尺寸与用途，未经过裁帧/动画检查的不标记为最终图集。
