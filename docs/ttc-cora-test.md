# 击倒TTC：八人和多场景

可选 Cora、Amber、Suki、Sid、Jilly、Laura、Kay、Franco，每局寻找所选人物的五个目标。场景包含胡同旧书摊，以及新增的旧物集市、温室花房。新增场景横向延长为 2160×720，视口保持 1280×720，支持鼠标拖动、手机左右滑动、滑条、左右按钮和 A/D；拖动不触发射击。

60 秒内逐个命中全部目标的可见不透明像素获胜；打空扣 3 秒。人物使用各自正式图集，尺寸为 26–32 像素宽、43–53 像素高，结合左右与下部遮挡；各藏点亮度为原图的 60%–69%，保留像素透明度。支持三倍放大镜、一次范围提示、重开和结果反馈。提示会移到尚未命中的目标附近；开始前不显示藏人。换人物或场景会重置本局，快速切换不会混用旧素材。尚未加入随机藏点及联网成绩。

游戏厅新增独立柜体，位于投篮机与球桌之间，柜体屏幕只有书架和准星，不绑定 Cora。靠近按 E 或点击机器，在当前窗口打开；Esc / 退出恢复世界焦点。底部碰撞由客户端、服务器和 NPC 共用的 walkability 规则处理。

直接预览：开发服务 `/ttc.html`；生产构建包含 `dist/ttc.html`。素材与提示词见 `assets/ttc/README.md`，模块位于 `src/ttc/`。
