## 根据合成画面修正的问题

最初独立家具的尺度、细节密度和机位混用。八张小桌拼接出现缝隙；调整尺寸后的两条长桌仍像桌岛，文化墙太大，桌面空，远排电脑落在桌面下方。用户截图指出这些问题后，继续修正了房间边界、桌排地面位置、桌面投影和公共装饰，不把尺寸参数通过当成美术验收通过。

当前胡同有两条完整连续长桌，分别贴两侧墙；四个座位属于每条桌排。八把椅子、八台电脑、四盆绿植、四个杯子和本人是独立对象。背景只包含墙、灰地毯、文化墙、中国结和低切面前墙。绿植与杯子取自照片可见的物件种类，布局用于样板，不代表确认了真人归属或习惯，也尚不可拿取。

两个固定机位参考 cyber-hutong 的同空间反向观察方案。新项目没有迁移旧人物身份、名字、座位或代码。文化墙属于真实右侧墙，另一机位观察普通白墙；端墙与入口在切换后换屏幕侧，但八个座位 ID 不变。

## 共用尺度与地面投影

源生成图尺寸不等于世界尺寸。各类型有统一尺寸合同，方向和状态帧共用该类型缩放，不能逐帧按包围盒拉到相同高度。

| 项目 | 世界尺寸 / 配置 | 实际画面像素 |
| --- | --- | --- |
| 世界 / 渲染画布 | 640×360 / 320×180 | 两个世界单位成为一个游戏像素 |
| 四人长桌总宽 | 480 | 240 |
| 单人工位宽 | 120 | 60 |
| 桌排整体投影高度 | 约 80–84，包含桌深与桌脚 | 约 40–42 |
| 网椅 | 最大宽 60，高 66 | 最大宽 30，高 33 |
| 笔记本电脑 | 最大宽 32，两个观察面保持同组比例 | 最大宽 16，用户侧约高 14、背侧约高 10 |
| 人物站立 / 坐姿高度 | 96 / 78 | 48 / 39 |
| 绿植 / 杯子高度 | 36 / 14 | 18 / 7 |

`src/layout.ts` 集中定义场景尺度：照片估算的房间横向深度 340、桌深 70、桌高 75 作为样板值；这些不是实地测量数据，也不推测本人的身高。展示使用同一地面压缩系数 .55 与高度投影系数 .60，形成适合像素小人的 2.5D 画面。

地面坐标为 `100 + physicalY × .55`。两条桌排的地面范围分别为 0–70、270–340；桌子地面落点与椅子脚底分开。桌面上的电脑、植物、杯子先投影它们的地面位置，再减去 `75 × .60` 的桌高。这样改变机位时，物件仍在同一张桌面上，不靠一套新屏幕偏移猜位置。

反向投影为 `screenX = 640 - worldX`、`screenY = 387 - worldY`；高度仍向上。L1–L4 / R1–R4 从端墙向入口编号，固定属于真实左 / 右墙。方向键始终按屏幕方向移动，反向机位将输入转换回世界方向。

桌排纹理也跟随反向观察水平翻转，保持抽屉与膝部空位的世界位置；不能只翻转座位坐标而保留桌下结构原样，导致同一个人换个机位就坐在抽屉前。

人物脚底是排序与位置锚点。站起返回同一椅子的通道站位；相同姿势的整张图集使用固定缩放和头部中心锚点，避免伸腿后按每帧高度归一化造成身体变大变小。远排坐姿不绘制从该机位应被桌椅遮住的直垂小腿，近排桌前缘遮住下半身，上身和电脑分别排序。素材检查隐藏桌椅时仍可查看完整人物帧。

## 验证与后续生产限制

真实浏览器键盘操作已逐一到达 R4、R3、R2、R1、L1、L2、L3、L4 并坐下；每个座位都切换机位检查同一 ID、同一世界位置及投影关系。动作检查左右六帧均实际播放，固定缩放不随帧变化。碰撞、反向屏幕移动、图层开关及快速视角切换亦在样板中检查。

快速轻按 E / V 曾在 Phaser 的输入队列中漏触发。操作键改为聚焦游戏时直接处理一次 DOM keydown；长按重复事件不重复切换，移动仍由引擎处理。互动时重新计算最近椅子，避免重置入口后立即按 E 使用过期目标。

最后逐次检查十次轻按 V，十次均切换；坐下后点击返回入口并立即按 E，角色保持在入口，没有用旧目标传回椅子。TypeScript 检查与 Vite 生产构建通过；浏览器无错误。生成样稿体积尚未优化，引擎打包仍有大块体积提示，不作为发布性能验收结果。

截图在 output/playwright/：hutong-current-culture.png、hutong-current-opposite.png 为当前两个机位；其他 v2 / v3 / v4 截图只记录途中版本，不作最终对比标准。

仍需区分运行网格与原始画法：同一低分辨率画布能统一像素颗粒，不能自动统一姿态、材质和色板。此次背景、家具来源与构图已经收敛，但人物手臂伸向键盘的姿态、椅子细节和桌面材质仍可继续精修；不把本轮称为最终美术验收通过。源 PNG 仍需要整理成可编辑的小尺寸像素母版与优化图集，才适合批量制作八个人。本人未提供的裤鞋仍为深色样稿；名字、真实性格、座位与其他七人资料没有推断或迁移。

界面仅围绕游戏操作、切换机位、素材图层与动作检查；未添加整页白色圆角外壳、装饰品牌图标、渐变光斑或卡片仪表盘。真实照片保存在 references/private/，没有放入生产资源。
