# 持物组合与侧面坐姿

最新尺寸：自由站立/移动高度 61.44（原站姿的 64%）；坐姿上身按高度 62.4 标定（恢复坐姿素材原大小的 80%）。家具继续保持 80%。用户希望两种状态独立调尺寸，因此不再共用缩放常量。

## 持物实现

用户否决人物×物件×动作的完整组合图方案。已查阅 [Phaser Container](https://docs.phaser.io/phaser/concepts/gameobjects/container)、[Spine Slots](https://us.esotericsoftware.com/spine-slots) 与 [Spine Runtime Skins](https://eu.esotericsoftware.com/spine-runtime-skins)，采用其部件变换、挂点、附件与绘制顺序的思路，在现有 Phaser 精灵管线中实现轻量组合，没有引入 Spine 运行时。

`src/held-item.ts` 管理角色手部挂点、独立物件与圆手前景。物件定义包括纹理、尺寸、颜色及握持原点；角色动作不包含具体物件。顺序为身体/手臂→物件→肤色圆手，物件对准握持位置，不再固定叠在角色腿旁。

空手持物上身使用 `owner-carry-empty-v1.png` 上排四个姿势；运行时仅使用前三个方向，左向镜像右向，以避开生成稿中未采用方向帧的错误。行走腿部复用原 `owner-side-walk-v2.png` 左右各六帧和原上下步态；持物上身与腿部独立合成。生成的持物步行整身稿不再作为实际腿部动画。坐下使用 `owner-seated-hold-empty-v1.png` 三向空手持物姿态。

原生工具保留了“带咖啡整身稿”作为试验记录，但运行时不引用：`owner-carry-coffee-v1.png`、`owner-seated-carry-v1.png`。当前物件仍是独立 `rest-kit/coffee-cup`。

挂点目前从角色肤色手部范围初始化，适用于本人的样稿；以后每个角色应导出/校准同名挂点元数据，避免依赖肤色识别。更换小物件需要独立物件图和握持配置，而非重画人物动作。单手拿杯、看手机、双手抱箱、撑伞应按动作类型分别配置；尚未实现手机/箱子/伞素材或八人皮肤换装。角色×物件×动作全组合不再作为素材计划。

## 侧面椅子

问题是脚底对齐无法保证臀部落在椅面，且缺少近侧遮挡。侧面人物按臀部/椅面坐点对齐，上身保持用户要求的比例，下腿作为独立纹理片段接到地面；没有改写原 PNG。侧椅的前沿及椅腿单独作为前景片段显示。空手和持物使用相同坐点与遮挡顺序。

## 验证

九把椅子持物试坐通过；后续坐点修改额外检查中间一桌左右侧椅的空手和持物四种状态。端杯左右行走采集到 `walk-legs-cell-0..5`、`walk-legs-cell-6..11` 全部六帧，停止后下身动态片段隐藏，持物站姿和独立杯子继续显示。恢复后的坐姿与较小的自由移动姿态在同一场景检查。生产构建通过。

最新动作截图：`output/playwright/carry-shared-legs.png`、`seat-hip-empty-4.png`、`seat-hip-carry-4.png`、`seat-hip-carry-5.png`。原始图像、提示与历史截图均保留。坐姿下腿作局部伸缩是本轮对齐方案，后续统一像素母版应改为直接按椅面锚点制作腿部素材，不把当前伸缩称为完整骨骼系统。
