# Laura v2：身体与袖子一体的动作素材

本规范覆盖 asset-standard-v1.md 中“独立手臂”的制作规则。64×80 逻辑画布、48 像素站立高度、地面基点 (32,72)、标准座面 (32,56)、物品及座具接口继续沿用。生成器输出是源图，实际尺寸和关节点须登记、检查，不能宣称提示词尺寸已经实现。

## 人物图层

- 身体帧包含头发、头部、躯干、双腿、肩膀、完整袖子及袖口。肩膀至袖口必须连续绘制；禁止单独旋转、缩放袖子后拼接到躯干。
- 空手姿态可以包含自然的小手。持物姿态的活动袖口应留出单独圆形手掌的接口；手掌直径 4 逻辑像素，物品独立挂载。不得在已有拳头旁再加一只手。
- 持物帧不是物品的排列组合：一组普通单手姿态可以绑定杯子、手机、瓶子等符合 one-hand-small-v1 的物品。双手或大型物品另用姿态模板。
- 空手与单手持物分别提供四方向站立、行走、坐姿及坐下过渡。行走须真实绘制两腿交替的六帧；身体和袖子同时绘制，不能运行时拼接独立手臂。
- 坐下三帧按站立、屈膝下降、落座绘制；起身可倒放同一组过渡，只有视觉验收连续后才启用。

## 登记与验收

每帧登记源矩形、统一倍率、脚底/臀部接触点、握持点。禁止自动按外轮廓各自缩放。生成原图保留，不进行破坏性覆盖。

先检查肩袖连续、袖子宽度、两腿交替、同一人外观稳定。再检查椅子和杯子组合；仅有人物源图时不得声称穿模已解决。正式游戏和场景素材不随本次候选生成自动替换。
