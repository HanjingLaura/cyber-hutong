# 厕所场景

使用照片中的暖色瓷砖、奶白门和白色陶瓷，按从右往左看的 2.5D 游戏视角重构，保留现有像素人物与步行效果。

背景只包含墙、地砖、灯和镜子。四个独立隔间门可开关，门打开后露出马桶和纸巾盒。两个盆嵌入一整条连续台面，位于右侧镜子下。门有 260 ms 收放过渡，洗手台有 1.5 秒流水反馈。

## 操作

- WASD / 方向键：移动。
- 门前 E：打开门；门开后 E：坐到马桶上。
- E / Esc：起身，回到同一隔间门外；门关着时自动打开。
- F：开关附近隔间门；坐着也可以关门。门口站着时禁止关门。
- 洗手台前 E：洗手。

## 尺寸、碰撞与遮挡

逻辑画布 640 × 360。隔间中心 x 为 80、170、260、350；独立隔间壳88×152，含侧墙、内壁与地面。门底 y=211，门58×130，打开后宽12。马桶用原图的水箱区域与独立盆体分层，移除穿过胳膊的竖起盖板；水箱24×10、底线169；盆体31×35、底线211。人物脚部 y=208，与隔间地面相接，臀部与盆体座面相接；复用已认可的62.4高度正面坐姿。坐姿渲染深度固定196，关闭的门211位于人物和手中物品之前。

连续双盆台面130×80，中心481、底线214；两个交互点x=450、512。流水位于台面前层，仅从龙头到盆内，不延伸到柜门。走路碰撞以脚部坐标计算，限制隔间墙、关门门槛、马桶占地、洗手台与右侧斜墙；起身出口固定在同隔间x、y=235。四个门复用同一素材和交互逻辑，四个马桶复用同一坐姿锚点。人物手中物品使用共享库存接口。

门、座位、手中物品在切换场景时保留；刷新会重置厕所门与座位状态。
