# 物品与彩蛋

四格背包继续保存每格最多五个同类物品。收藏是单独持久化的物品空间，收进收藏会移走手中物品，取回时再交回手中，不复制物品。设置中的收藏册和背包的收藏页使用同一份数据。食物、饮料通过手中物品按钮或背包的吃喝按钮消耗，结果由后端确认并保存经历。

熨烫后的拼豆可以选择拿走或收藏。每件作品只能领取一次；独立物件保留实际的豆子颜色与排列，支持手持、背包、收藏、赠送以及回看。抓娃娃由后端验证设备使用权、瞄准位置和完整的落爪、回升、出货时间；实际成功后获得对应娃娃，手里已有物品时自动进入收藏。结束前关闭机器会取消该轮。扭蛋使用透明底独立像素玩具，展示图、手持物和收藏图使用同一素材。

米线店凳子前景遮挡与回看一致。舞室停止动作时取消节拍定时器和已调度的声音，包括练习自动结束、手动结束和离开场景。

个人彩蛋所有在场玩家都能看见，互动权限在后端校验。Ani / Sid，噜噜 / Suki，图图 / Kay，巴斯光年 / Cora，朱志鑫 / Jilly，富贵貂 / Amber。主人走近后按 E 或点击彩蛋互动；Sid 坐着办公时可以点击 Ani 或互动按钮。其他玩家可以看到互动气泡，经历只保存到实际互动者的记录中。

Celine 是共享的自动来访者，不开放主动互动。每 5–9 分钟随机决定在夏威夷、胡同或暂时不出现，同一时间只在一个地点。胡同只站立或沿通道走动；夏威夷在空闲的右下角 HL3 坐下，并偶尔起身走动。到访后首次发言等待 45–90 秒，此后每 90–180 秒选择台词：Amber 呢？60%，Jilly 呢？25%，Amber 这孩子。15%。随机决定保存在数据库，所有客户端共用，不因切换场景或刷新重新抽取。

验证：`npm test`、`npm run build`、`node scripts/verify-collectibles.mjs`、`node scripts/verify-easter.mjs`。浏览器验收使用独立数据库和临时账号，不改正式数据。
