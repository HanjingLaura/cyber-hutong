# 门口地点地图

2026-10-03 已实现，采用本轮确认的门口地图，不新增走廊或街道。

14 个房间的入口、出口、分组集中在 shared/rooms.json。地图按办公、休闲、出行分组，显示实际名称与当前位置。顶部地图可以查看；切换须先结束互动、走到出口标记，按 E 打开地图，再选择目的地并确认。电梯与地铁仍仅开关门。

客户端先加载目标素材，再提交 /api/transition。服务端检查操作窗口、目标、出口距离、座位和设备占用；成功后释放旧占用，更新同一个玩家记录，在目标入口出现。角色、手持和私聊对象保留，场景聊天随房间变化。

素材失败或超时发生在服务端提交前，仍留在原场景，可以重试；提交后渲染异常则按服务端房间恢复。同账号观看窗口跟随房间，不能自行瞬移。正式界面移除试玩切换，开发检查只在开发模式 ?debug=1 显示。

服务端验证移动速度与交互锚点；完整家具碰撞网格仍在客户端，不将当前检查视为完整防作弊系统。
