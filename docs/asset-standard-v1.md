# hutong-online 人物、持物、座具素材标准 v1

状态：新素材制作规范，尚未替换当前游戏素材。先做一个人物、一把基准椅子、一只基准杯的适配样板，再按这个模板制作整套动作及其他角色。

## 1. 尺寸与坐标

- 逻辑画面为 640×360；1 个素材像素对应 1 个世界单位。放大画面使用整数倍最近邻显示；不单独拉伸人物、椅子、杯子，也不靠透明边界自动推算大小。
- 人物所有动作帧固定为 **64×80** 透明 PNG。左上为 (0,0)，右为 +X，下为 +Y。站立地面基点固定为 **(32,72)**。
- 基准人物站立可见高度 **48 px**，坐姿约 **46 px**。头部参考框 **22×20 px**，躯干参考高 **10 px**。同一角色不同动作的头部、躯干尺寸不变。
- 坐下通过屈腿和位移实现，不切开后拉长裤腿或鞋子；站立和坐姿不使用两套缩放倍率。发型、服装可改变轮廓，不能改变关节和互动挂点。
- 第一阶段八个人共用一副基准体型。差异先放在发型、眼镜、服装、肤色等外观上；不同身高及体型以后作为独立适配规格增加。
- 相机视角属于场景；正面、背面、左右侧面使用对应方向素材。不能把带透视的椅子或不对称人物简单镜像后当作另一方向。

这些尺寸是新一版的制作尺寸，不是对现实厘米数的推算。现有素材仅作风格及身份参考，不能继续沿用其随机裁边和不同缩放比例。

## 2. 人物动作与图层

首套人物动作覆盖四个方向：南/正面、北/背面、东/向右、西/向左。

| 动作 | 每个方向帧数 | 制作规则 |
| --- | ---: | --- |
| 站立 | 1 | 双脚落地；头和身体位置稳定 |
| 行走 | 6 | 左脚前、回收、交错、右脚前、回收、交错；左右腿分别制作 |
| 坐姿 | 1 | 臀部对齐座面；膝盖在座面前缘之外；脚底落地 |
| 坐下过渡 | 3 | 靠近、屈膝、落座；关节与最终坐姿连续 |
| 起身过渡 | 3 | 离座、伸腿、站稳；最终回到站立基点 |
| 持物手臂 | 每方向站姿和坐姿各 1 套 | 短曲臂、圆手；物品单独挂载；移动时保留原六帧腿部 |

呼吸等小幅动画待基础动作验收后再增加。首套不需要为每一种物品另画一组动作。

交付人物身体、互动手臂/圆手及必要的前后遮挡层。持物时隐藏被替换的普通手臂，不能在普通身体上再补一条袖子、留下两只同侧手。手臂颜色属于角色的服装配置。

每帧显式记录地面基点、臀部、肩、肘、握持点；不能靠识别肤色猜手的位置。动作切换按这些点对齐，不能重新按每帧外轮廓居中。

## 3. 统一持物接口

常规单手物品使用 `one-hand-small-v1` 规格。

| 项目 | 标准 |
| --- | --- |
| 物品画布 | 16×16，透明，留空由固定挂点处理 |
| 常规可见轮廓 | 最大 10×12；咖啡杯先用 8×9 |
| 手 | 直径 4 px 的圆形手，外轮廓 1 px；不得包住整个杯身 |
| 角色正面握持点 | 站姿 (23,49)，坐姿 (23,51)，向左外伸 |
| 角色背面握持点 | 站姿 (41,49)，坐姿 (41,51)，向右外伸 |
| 角色向右握持点 | 站姿 (42,49)，坐姿 (42,51)，向右外伸 |
| 角色向左握持点 | 站姿 (22,49)，坐姿 (22,51)，向左外伸 |
| 基准杯物品挂点 | 向左持杯版本 (11,8)，向右持杯版本 (5,8)；挂点位于靠近人物的杯柄处 |

物品位置 = 人物当前动作的握持点 − 物品自身的握持点。二者相合，不以物品图片中心定位。物品元数据同时提供可见轮廓和与手允许接触的区域。

杯柄、瓶身、手机边缘的握法通过物品自己的挂点定义；人物复用同一套手臂。物品可提供四方向外观；确实对称的物品可复用外观，但不能镜像文字或不对称结构。

允许手与杯柄等握持区域重叠；杯身与胸口、袖子、大腿的可见轮廓不得相交。对超出 10×12 的物品先拒绝套用此规格，另建 `two-hand`、`large-carry` 或工具动作规格；不能承诺单一动作适配任意大小和用途的物品。

## 4. 统一座具接口

普通办公椅、餐椅首先都满足 `seat-standard-v1`。椅子可换外观，但座面及支撑必须遵守接口。

| 项目 | 标准 |
| --- | --- |
| 基准椅画布 | 64×80，透明 |
| 地面基点 | (32,72) |
| 座面挂点 | (32,56)，距地面 16 px，表示臀部接触的座面上表面 |
| 基准座面可见宽度 | 正面 24 px；侧面示例 X=22…41，厚度最多 3 px |
| 椅背最高处 | 参考 Y=36；外观可变化，但不能进入人物需要露出的轮廓 |
| 侧面前支撑示例 | 向右坐时 X=36…39；镜向椅另制作对应支撑 |
| 侧面膝/小腿示例 | 向右坐时膝 X=44，腿 X=44…48；与椅子前支撑至少保留 3 px 可见间隔 |
| 坐姿人物臀部挂点 | (32,56)，直接与椅子座面挂点对齐 |
| 侧面脚底 | 向右坐的鞋底 Y=72；鞋子参考 X=44…51，向左对应镜向坐姿 |

角色臀部挂点与座具挂点重合即可落座，不按角色姓名、椅子型号逐个写偏移。椅子的脚踏或扶手不能侵入基准人物的腿部、持物活动区域。

座具分为 `back`（椅背和后方结构）、`seat`（座面）、`front`（确实位于人物前面的扶手等局部）。没有前景结构的侧椅可以没有 `front` 层；不能把整块椅面和椅腿复制到人物前方。

沙发、凳子只有在满足同样座面高度和留空范围时才能复用此坐姿。高脚凳、躺椅、不同座面高度需另建规格，声明支持的姿势，不能缩放人去迁就。

## 5. 场景和遮挡

- 地板、墙面、固定装饰属于场景底层。人物、电脑、杯子、咖啡机、贩卖机、餐桌和座具独立素材。
- 行走碰撞使用脚底的小范围形状；物件碰撞使用地面占地。两者都不等于整张图片的透明矩形。
- 普通房间物件按地面基点排序。同一坐姿组合内部按“椅背/后支撑 → 座面 → 人物 → 确有必要的前景部件”排序。
- 圆手覆盖允许握持的物品区域。背面姿态的手臂、物品需要单独声明前后关系；不能无论朝向都画在脸或身体前面。
- 餐桌必须提供桌面范围、桌面高度、腿部留空范围及四方向座位挂点。桌面参考距地面 24 px，常规座面距地面 16 px；电脑等物品落在桌面范围内。
- 餐桌旁持杯时检查杯子与桌面的可见接触位置。不能用提高所有物品的绘制层级掩盖穿模。

胡同两个视角分别使用对应方向的物件素材和遮挡规则，同一物件的逻辑尺寸和身份保持一致。

## 6. 素材登记与验收

人物元数据包含 `rigProfile`、方向/动作/帧、画布尺寸、固定缩放、关节挂点、身体图层及轮廓。物品包含 `gripProfile`、各方向握持点、手允许接触区、外观尺寸。椅子包含 `seatProfile`、座面挂点、层级、占地、腿部及持物留空区。

加载时检查规格、尺寸和挂点；不兼容的组合不得默默显示。制作时使用带座面线、地面线、关节点、轮廓及留空区的参考模板，最终交付时关闭参考线。

验收分两部分：

1. **几何检查**：人物脚底在地面；臀部贴座面；物品与手挂点相合；腿部与座具禁入区域不相交；杯身不进入身体轮廓。只检查允许接触的部位，不能把所有像素重叠都判成错误。
2. **视觉检查**：原始 1 倍和最近邻 4 倍逐帧查看；侧面椅腿与人物裤腿能分辨；只有一条持物手臂；没有袖子横杆、浮空臀部、断腿、被拉长的鞋、动作切换跳位。检查站立/走路/停步/持物坐下/起身/放下物品。

先验证基准人物与杯子、瓶子、手机及办公椅、餐椅的组合。增加人物时用这些基准道具验收；增加道具时用基准人物和尺寸边界模板验收。每次发布再跑全部已登记组合的自动几何检查，并抽看视觉接触图。

统一接口能减少组合数量及反复调偏移，但挂点合格不等于视觉必然合格；新素材仍须通过轮廓与动作验收。

## 7. 重做顺序

1. 固定以上模板和基准人物体型。
2. 先制作一人四方向站姿、四方向坐姿、持物手臂，以及一把基准椅、一只杯的样板。
3. 样板完成几何及放大视觉验收，再生成六帧行走、坐下与起身过渡；不把未验证模板扩散到整套素材。
4. 补齐杯子、瓶子、手机、办公椅、餐椅，验证同动作跨物件适配。
5. 用同模板制作后续七个人，替换当前自动裁边、肤色识别挂点、矩形袖子补丁和拉腿逻辑。

生成工具的输出须逐帧筛选并校准到模板；不能把生成提示词中的尺寸要求当作已经完成的验收。
