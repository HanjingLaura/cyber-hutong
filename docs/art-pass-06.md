# 持物与侧面坐姿接触修正

上次仅验证动作播放，对视觉穿模的判断有误。本次按实际浏览器画面的四倍放大截图检查。

- 持物挂点从手部位置扩展到身体外缘，杯身朝外，圆手叠在内侧握持点。袖子连接原前臂与挂点，并覆盖原素材的 C 形手。
- 手部识别改为候选区域内最大连通肤色块，避免领口像素导致只识别半只手。
- 侧面椅子保留后景层，删除把椅面和两条支撑整块重画到人物前方的覆盖层。
- 侧坐臀部位置与椅面对应，人物朝椅子前方移动五个世界单位；小腿适配落地高度，鞋子独立切帧并保持原比例。
- 行走仍使用既有左右各六帧腿部，不新增人物与物品的组合素材。
