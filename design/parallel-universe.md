# 平行宇宙 · 产品主循环

Laura 拍板（高于画风）。画廊只是素材预览；产品三层必须按这个做。

## 三层

| 层 | 谁在动小人 | 信号从哪来 |
|----|------------|------------|
| **Online-control · 本人在线** | 玩家直接操控自己的小人 | 键盘/点击：移动、进房、把杯子/本/盲盒放到**空桌位**、触发对话 |
| **Offline-agent · 本人离线** | 该角色的 agent 驱动**同一个**小人在胡同里活动 | 用已学到的行为模式选房间、停留、摆物、找谁聊天、摸鱼 |
| **Behavior-learning · 学习** | 不另造角色 | **在线操作日志（行为轨迹）** 才是持续训练/更新信号 |

蒸馏 Q&A / PersonaCard **只做冷启动**，不是日常驱动。人上线玩过之后，以轨迹为准改卡。

```
冷启动（蒸馏题） → PersonaCard_0
        ↓
本人在线操控 ──记录──→ 操作事件流（进房/停留/摆物/社交/摸鱼）
        ↓
规则合并进 PersonaCard（房间权重、桌面习惯、社交对象…）
        ↓
本人离线 ← agent 按更新后的卡回放/抽样事件牌
```

## MVP（本周不必接大模型）

1. 录操作事件：`{t, room, action, slot?, target?}`
2. 规则/事件牌回放：离线时按频率抽「去夏威夷开机 / 拆一个盒 / 回胡同空位放杯」
3. 卡字段与事件映射写在 [`distill-spec.md`](distill-spec.md)
4. 预览：画廊「一天」= 一条可被卡过滤的事件牌序列，不是「纯 agent 演完一天」

## 房间与物位

agent 和玩家用同一套 7 房、同一套桌面空位。离线摆物只能放进已留空的 pad，不能堆死桌面。

下架房（茶水间/打印/楼梯/天台/老板办/快递门口）不进事件空间。
