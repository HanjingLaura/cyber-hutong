# 平行宇宙 · 产品主循环

Laura 刚定。**高于画风**：场景和八人精致像素是皮，主循环是骨。画廊只是素材预览，不能只画画。

同一小人只有一个。在线由本人操控；离线由该角色的 agent 驱动；agent 必须学习真人在线时的操作。蒸馏 Q&A / PersonaCard **只做冷启动**。

## 三层

| 层 | 英文 | 谁在动小人 | 信号从哪来 |
|----|------|------------|------------|
| **本人在线** | Online-control | 玩家直接操控自己的小人 | 键盘 / 点击：移动、进房、把杯子 / 本 / 盲盒放到**空桌位**、触发对话 |
| **本人离线** | Offline-agent | 该角色的 agent 驱动**同一个**小人在胡同里活动 | 用已学到的行为模式选房间、停留、摆物、找谁聊天、摸鱼 |
| **学习** | Behavior-learning | 不另造角色 | **在线操作日志（行为轨迹）** 才是持续训练 / 更新信号 |

蒸馏题填出的 PersonaCard_0 只在「还没玩过」时用。人上线玩过之后，以轨迹为准改卡；蒸馏字段与轨迹冲突时 **轨迹赢**。

```
冷启动（蒸馏 Q&A） → PersonaCard_0
        ↓
本人在线操控 ──记录──→ 操作事件流
        │              进房 / 停留时长 / 桌面摆物 / 社交对象 / 摸鱼偏好
        ↓
规则合并进 PersonaCard（房间权重、桌面习惯、社交、摸鱼…）
        ↓
本人离线 ← agent 按更新后的卡驱动同一小人（回放 / 抽事件牌）
```

## 1 · Online-control · 本人在线

玩家直接操控自己的小人，不是看 agent 演戏。

最少操作（与 7 房、空桌位对齐）：

| 操作 | 事件 `action` | 记什么 |
|------|----------------|--------|
| 移动 | `move` | 房间内坐标或路径摘要 |
| 进房 | `enter_room` | `room`、进入时刻 |
| 离开 | `leave_room` | `room`、停留时长 |
| 往空桌位放东西 | `place_item` | `room`、`slot`、`item` ∈ cup / notebook / blindbox / laptop |
| 从桌位拿走 | `take_item` | `room`、`slot` |
| 触发对话 | `talk` | `target` = 另一 cast id |
| 摸鱼动作 | `slack` | 拆盒 / 洗手磨蹭 / 窗边发呆… |

在线时 **不** 用 PersonaCard 替玩家做决定。卡只在离线时被 agent 读。

## 2 · Offline-agent · 本人离线

本人不在时，**该角色的 agent** 驱动**同一个**小人在胡同里活动（同一 `castId`、同一套 7 房、同一套桌面空位）。

离线可做的事与在线同一套动词：进房、停留、往已留空的 pad 摆物、找 `social` 里的人说话、按 `slackOff` 去摸鱼。

离线摆物只能放进已留空的 pad，不能堆死桌面。下架房（茶水间 / 打印 / 楼梯 / 天台 / 老板办 / 快递门口）不进事件空间。

离线 **不是**「纯 agent 演完一天」。一天故事板是默认可被卡过滤的事件牌，见下节 MVP。

## 3 · Behavior-learning · 学习

agent **必须**学习真人在线时的操作行为模式，至少：

| 模式 | 从哪些事件来 | 写入 PersonaCard |
|------|----------------|------------------|
| 常去房间 | `enter_room` 计数 | `favoriteRooms` |
| 停留时长 | `leave_room` 的 dwell | 房间权重 / `slackOff` |
| 桌面摆物习惯 | `place_item` 的 room+slot+item | `deskHabit` |
| 社交对象 | `talk.target` | `social` |
| 摸鱼偏好 | 在 popmart / restroom / hawaii 的停留与 `slack` | `slackOff` |

**在线操作日志（行为轨迹）才是持续训练 / 更新信号。**  
蒸馏 Q&A / PersonaCard **只做冷启动**，不是日常大脑。合并公式与规则见 [`distill-spec.md`](distill-spec.md)。

## MVP（本周不必接大模型）

先能转起来，不接 LLM：

1. **录操作事件**：`{t, room, action, slot?, item?, target?, dwell_s?}`
2. **规则 / 事件牌回放**：离线时按 PersonaCard 频率抽牌  
   例：去夏威夷开机 / 拆一个盒 / 回胡同空位放杯
3. **卡字段 ↔ 事件** 写在 [`distill-spec.md`](distill-spec.md)
4. **预览**：画廊「一天」= 一条可被卡过滤的默认事件牌，**不是**「纯 agent 演完一天」

本周不做：大模型编旁白、在线推理、自动生成一整天剧本。

## 和视觉任务的关系

精致像素 7 房 + 八人 cast **继续做，不冲突**。空桌位、一边四座、只链保留房，是为了让在线摆物和离线回放共用同一套物位。主循环以本文件为准，不画在 PNG 里。
