# 「赛博胡同」美术简报（精致像素重做）

> 阶段目标：像素资源与预览画廊。无 Agent / LLM / 鉴权 / 数据库。
> Laura 过夜纠正：精致像素、地图小但细、桌椅留物位、只做点名场景、八人按参考重画。

## 定位

- **类型**：2.5D 斜俯视像素探索小品（仍可读体积，不再用过夜那种粗块）
- **题材**：公司日常 × 一点点赛博（霓虹只作点缀）
- **画风**：readable tiny detail · 干净 1px 描边 · 统一调色

## 视角

| 要点 | 约定 |
|------|------|
| 相机 | 略俯，能看见桌面顶面和椅背 |
| 角色 | 大头小身 chibi，不是写实肖像 |
| 深度 | 阴影、墙厚、遮挡；胡同工位是过道朝墙看一条横长桌 |
| 轮廓 | **1px** 深色描边，不要 2px 粗块 |
| 缩放 | `image-rendering: pixelated`，整数倍 |

## 只做这些场景

| 场景 | 地板 | 光 | 硬规则 |
|------|------|----|--------|
| 胡同工位区 | 浅灰地 | 白墙顶灯 | 远墙一条浅色长桌，一侧四座朝墙，桌面留空。纵深办公室照只作气氛 |
| 电梯间 | 白石大理石 | 筒灯暖白 | 米黄石材、开门、雕塑、屏与按钮 |
| 夏威夷 | 暖木 | 卷帘缝日光 | 窗边，座位留物位 |
| 泡泡玛特 | 粉×薄荷细格 | 粉/青灯带 | 柜台不要堆死 |
| 厕所 | pastel 瓷 | 暖白 | 四隔间 + 两水池 |
| 普通工位 | 冷灰地毯砖 | 窗光 | 岛式桌，与胡同长桌区分 |
| 会议室 | 暖灰 | 屏青光 | 桌面中央留空 |

**下架**：茶水间、打印区、楼梯过道、天台、老板办公室、快递门口、旧胡同口。

## 规格

- 场景合成：**256×192**
- 角色帧：32×32
- 道具：6–16 px 小件（杯 / 本 / 盲盒 / 笔记本）

## 产品主循环（高于画风，不要只画画）

以 [`parallel-universe.md`](parallel-universe.md) 为准：

1. **Online-control · 本人在线** — 玩家直接操控自己的小人（移动 / 进房 / 往空桌位放东西 / 对话）。
2. **Offline-agent · 本人离线** — 该角色的 agent 驱动**同一个**小人在胡同里活动。
3. **Behavior-learning · 学习** — agent 学真人在线操作（常去房、停留、摆物、社交、摸鱼）。蒸馏 Q&A / PersonaCard **只做冷启动**；在线操作日志才是持续更新信号。

MVP：录操作事件 → 规则 / 事件牌回放。本周不必接大模型。合并规则见 [`distill-spec.md`](distill-spec.md)。

## 非目标

动画状态机、碰撞、战斗、存档、登录、本周接大模型、真人照片入库。
