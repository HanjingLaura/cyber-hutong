# 场景：泡泡玛特店（Pop Mart）

> Phase-1 命名场景。胡同里的潮玩店内景，Soul Knight 式 2.5D 斜俯视像素。核心互动意象：**拆盲盒**。

## 场景身份（必须与其它场景一眼可辨）

| 维度 | 本场景 |
|------|--------|
| 地板 | **粉×薄荷糖果格** — 禁止深蓝网格 / 办公木地板 |
| 墙面 | 紫粉零售面板 + 整面盲盒墙 |
| 光照 | 粉 / 青绿霓虹灯带 + 橱窗闪光 |
| 情绪 | 明亮糖果零售，绝不能像办公室 |

## 布局要点

- **室内店面**：糖果格地板 + 紫粉后墙，粉青灯带压顶
- **货架 / 盲盒墙**：后墙与两侧彩色方盒堆叠
- **展示柜台**：中央玻璃台面柜台，可摆未开盒
- **拆盲盒区**：柜台旁放置 **未开盲盒**、**已拆开盒 + 手办剪影**

## 像素约定

- 瓦片 32×32；场景合成约 320×240
- 调色：马卡龙盒色（粉 / 薄荷 / 黄 / 丁香 / 天蓝 / 橙）+ 霓虹描边
- Soul Knight：盒体 chunky 外轮廓，柜台玻璃高光

## 非目标

不做真实品牌 Logo 复刻、不做抽卡系统逻辑、不做支付 / 库存。
