# Google 总结会纪念票

两张头像图集由用户提供的「赛博胡同-八人-图片1.zip」票面参考生成，保持八个人的发型、配饰与对应配色。

- portraits-1.png：左上 Suki、右上 Sid、左下 Jilly、右下 Laura。
- portraits-2.png：左上 Kay、右上 Franco、左下 Cora、右下 Amber。

身份与旅行字段统一保存在 shared/memory-tickets.json。后端从账号绑定角色选择票；前端使用同一份清单选择名字与头像，旧领取记录无需重新领取。

Cora 的实拍原图分辨率不足。用户补充其姓名为 CoraKong，并授权参考其他人的票另配航班号、登机口等字段，因此采用 Cora Kong / TT523 / B08 / 14A。其余七张的姓名、航班号、登机口与座位均按参考图录入。

这是团队纪念票，票面条纹为装饰，不作为真实登机凭证或个人领取验证码。
